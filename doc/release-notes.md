## 0.1.5 旧存档覆盖确认与 EXE 图标修正

- 点击“本地同步到云端”或“云端同步到本地”时实时核对两端存档时间。旧存档覆盖新存档会再次确认，显示本地时间、云端时间和覆盖方向；取消后不传输、不修改存档。
- 确认后重新核对账号、存档内容、时间、路径及云端版本；发生变化则停止同步，避免沿用过期确认。保留进度冲突提示和覆盖前本地备份。
- 修正 EXE 图标的小尺寸格式，云存档图标同时提供传统 DIB 和高分辨率 PNG；Windows CI 核对最终 EXE 内嵌的全部图标尺寸。
- 保留应用内下载、SHA-256 校验、替换失败回滚和自动重启；配置、登录信息及本地备份仍保留在程序旁的 `data`、`backups`。

适用于 Windows 10/11 x64。下载 ZIP 后完整解压，运行 `UmeYc-SteamBack-Windows.exe`，无需安装 Python。程序未签名。

v0.1.4 可点击“检查更新”，再点击“下载并更新”升级。请先退出游戏并等待存档同步完成；程序目录需要可写。手动升级或移动时保留 `data`、`backups` 文件夹；移动后需重新配置 Steam 启动项。在其他 Windows 用户或电脑上使用需要重新扫码登录。

**v0.1.3 及更早版本需要手动下载，退出工具后完整解压覆盖一次；保留 `data`、`backups`。之后即可在应用内更新。**
