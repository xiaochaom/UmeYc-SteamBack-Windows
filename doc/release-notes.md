## 0.1.6 修复重启更新被缓存状态拦截

- 修复“重启并更新”被过期游戏会话或缓存运行状态持续拦截的问题；更新前重新检测 Steam 和游戏进程，覆盖当前列表及已配置游戏。
- 若游戏仍在运行，显示具体游戏名称；若当前存档操作尚未完成，自动等待并重新检查，无需反复点击。
- 更新前持久保存刚退出游戏的待上传任务及原同步基准，保留现有断网补传与冲突保护。
- 保留旧存档覆盖新存档的二次确认、EXE 云存档图标、应用内更新校验、回滚和重启；配置与备份不受影响。

适用于 Windows 10/11 x64。下载 ZIP 后完整解压，运行 `UmeYc-SteamBack-Windows.exe`，无需安装 Python。程序未签名。

v0.1.4 / v0.1.5 可点击“检查更新”，再点击“下载并更新”升级。若旧版提示等待游戏退出但实际已退出，请先从托盘彻底退出工具并重新打开，以清除旧版缓存；仍无法更新时手动下载并完整解压覆盖，保留 `data`、`backups`。请先退出游戏并等待当前存档操作完成，程序目录需要可写。

**v0.1.3 及更早版本需要手动下载，退出工具后完整解压覆盖一次；保留 `data`、`backups`。之后即可在应用内更新。**
