## 0.1.4 应用内下载并更新

- “下载新版”改为“下载并更新”：在应用内下载正式安装包并显示进度，验证 SHA-256 后退出旧版、替换程序、自动重启。
- 游戏或存档同步未结束时，保留已校验的更新包，提示空闲后点“重启并更新”；更新时暂停新的同步启动请求。
- 程序替换仅涉及 EXE、运行库及文档，保留 `data`、`backups`、登录会话、待补传队列及用户其他文件；替换失败恢复旧程序并重新打开。
- 更新包和暂存文件放在程序旁的 `data/updates`，不写入 C 盘用户目录。
- 增加下载校验、解压防护、文件占用、回滚、数据保留测试；Windows CI 实际运行打包更新进程并验证重启后的 EXE。
- 保留 v0.1.3 的便携数据目录、旧版数据迁移、直接恢复云存档、昵称及云存档图标。

适用于 Windows 10/11 x64。下载 ZIP 后完整解压，运行 `UmeYc-SteamBack-Windows.exe`，无需安装 Python。程序未签名。

更新前等待同步完成并退出旧版，将新程序完整解压到原程序目录。升级或移动时保留 `data`、`backups` 文件夹；程序目录需要可写，移动后需重新配置 Steam 启动项。在其他 Windows 用户或电脑上使用需要重新扫码登录。

**v0.1.3 及更早版本还没有自动替换能力，需要最后手动下载、完整解压覆盖一次。升级到 v0.1.4 后，后续版本可在应用内点击“下载并更新”。**
