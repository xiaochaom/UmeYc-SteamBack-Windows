首个 Windows 版，可通过夸克网盘与 UmeYc-SteamBack Steam Deck 插件交换游戏存档。

- 全中文桌面界面，Steam 多游戏库/账号识别，支持手动添加 App ID。
- 夸克扫码登录，昵称/用户 ID 显示，登录会话使用 Windows DPAPI 加密。
- 存档路径候选识别、手动选择与文件变化嗅探。
- 手动本地备份、重命名、恢复和删除；本地备份持续保留。
- 双向云同步，目录逐项对应，显示本地与云端存档时间，云端只保留最新一份。
- 覆盖前保留本地备份；同步校验和冲突确认；每游戏退出自动上传默认关闭。

下载 `UmeYc-SteamBack-Windows.zip` 后完整解压，运行同名 EXE，适用于 Windows 10/11 x64，无需 Python。`SHA256.txt` 为校验文件。

首次互通建议先在 Deck 上传，再在 Windows 下载时确认对应文件夹。两端需使用同一夸克账号、Steam 账号和游戏 App ID，游戏存档格式本身需兼容。

Windows CI 已验证自动测试、打包和 EXE 启动。真实扫码登录、夸克传输与实际游戏跨设备互通仍需联调；初次使用建议先保留原始存档副本。程序未签名。
