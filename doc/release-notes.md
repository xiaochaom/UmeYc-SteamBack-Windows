## 0.1.13 修复从 Steam 启动时误报游戏正在运行

- 修复 Windows 系统伪进程 Registry、MemCompression 返回相对名称时，被按游戏工作目录解析并误判为游戏运行的问题。
- 运行检测仅使用绝对可执行文件路径，保留真实游戏进程检查、启动前同步及存档冲突保护。
- 增加以游戏目录为工作目录的回归测试，并修正启动项测试在中文 Windows 默认编码下的读取方式。

Windows 10/11 x64。可通过“检查更新”升级；若旧版卡在准备更新，请结束本工具进程后完整解压覆盖，保留 `data`、`backups`。已配置的 Steam 启动项继续有效，无需重新配置。程序未签名。
