## 0.1.2 启动检查更新与统一游戏列表

- 每次程序启动时在独立后台任务中检查 GitHub 最新正式版本；重新打开已有后台主机也会检查。
- 发现新版显示版本号与“下载新版”入口，支持手动检查。断网、超时或更新服务异常不影响存档同步及游戏启动；后台不弹窗。
- 取消 Steam 云支持情况分组，全部游戏统一按名称排列，继续过滤 Proton 等兼容层。
- 保留按需启动、自动云同步、手动选择同步方向、断网补传及冲突保护、本地备份与路径嗅探。

适用于 Windows 10/11 x64。下载 ZIP 后完整解压，运行 UmeYc-SteamBack-Windows.exe，无需安装 Python。程序未签名。

更新前请等待当前同步完成并退出工具，将新程序解压到原目录，保留已配置的 Steam 启动项路径。应用数据及本地备份独立存储，不随程序替换删除。
