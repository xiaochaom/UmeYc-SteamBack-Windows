## 0.1.1 统一自动云同步与按需后台主机

- 每个游戏使用一个“自动云同步”开关：开始游戏前同步，退出游戏后自动上传，默认关闭。
- Windows 通过 Steam 启动项保留原有 `%command%` 参数；Steam 正常启动和原有快捷方式都能经过同步入口，无需开机自启。
- 后台主机按需启动，隐藏窗口并减少页面刷新；游戏退出后等待存档写入稳定，再上传，完成后自动退出。
- 断网或上传失败会持久保存待补传任务。每次补传重新检查云端内容；云端出现不同进度时暂停，不自动覆盖，内容一致时不重复上传。
- 游戏页提供“手动同步”入口，显示本地和云端时间，可选择使用本地上传或使用云端下载。
- 过滤 Steam 兼容层，并按 Steam 云存档支持情况分组；保留手动路径、嗅探、本地备份和安全恢复能力。

下载 ZIP 后完整解压，运行 UmeYc-SteamBack-Windows.exe。适用于 Windows 10/11 x64，无需 Python，程序未签名。真实夸克账号、Steam 启动项和具体游戏互通仍需设备联调。
