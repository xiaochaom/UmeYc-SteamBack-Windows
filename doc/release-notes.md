## 0.1.3 便携数据目录与直接恢复云存档

- 配置、加密登录信息、同步记录、待补传队列及临时文件统一保存到程序旁的 `data` 文件夹；本地存档备份放在程序旁的 `backups`，跟随程序所在磁盘。
- 首次启动迁移旧版用户目录中的数据与所有账号的备份；复制校验成功后才删除原文件，冲突或迁移失败时停止并提示。
- 云端同步到本地直接覆盖已配置的实际游戏存档路径，取消逐目录映射确认；未配置路径时先选择一次，覆盖前保留安全备份。
- 夸克和 Steam 账号栏仅显示昵称，账号 ID 仍用于内部隔离存档。
- Windows EXE、窗口和任务栏统一使用云存档图标。
- 保留启动检查更新、Steam 启动前同步、退出后上传、断网补传和冲突保护。

适用于 Windows 10/11 x64。下载 ZIP 后完整解压，运行 `UmeYc-SteamBack-Windows.exe`，无需安装 Python。程序未签名。

更新前等待同步完成并退出旧版，将新程序完整解压到原程序目录。升级或移动时保留 `data`、`backups` 文件夹；程序目录需要可写，移动后需重新配置 Steam 启动项。在其他 Windows 用户或电脑上使用需要重新扫码登录。

旧版 v0.1.2 可通过“检查更新”发现本版本并打开下载页；更新包需要手动下载、解压替换。
