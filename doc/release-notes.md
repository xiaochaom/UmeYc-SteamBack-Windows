## 0.1.7 修复时间显示、界面闪烁并移除托盘

- 修复同步完成后云端存档时间、上传时间显示“暂无”；上传、下载及后台上传直接显示实际云端版本时间，内容一致时保留原上传时间。
- 修复开启自动云同步后每隔几秒界面闪烁；只读检查不再反复禁用界面，刷新页面不会误触发开关。
- 移除系统托盘，管理窗口打开即用、关闭即退出；正在处理存档时完成当前操作后自动退出。
- Steam 启动项负责开始前同步和退出后上传。游戏期间关闭管理窗口，退出游戏时仍可按需唤起上传进程；空闲管理窗口不持续扫描游戏。
- 替换 EXE 后及升级后的首次启动通知 Windows 刷新“云＋存档”图标，减少旧图标缓存；构建同时验证 EXE 默认图标资源及 Windows 原生提取结果。
- 保留旧存档覆盖新存档的二次确认、断网补传冲突保护、更新校验与失败回滚；配置和备份保留。

适用于 Windows 10/11 x64。下载 ZIP 后完整解压，运行 `UmeYc-SteamBack-Windows.exe`，无需安装 Python。程序未签名。

v0.1.4 及以后版本可点击“检查更新”，再点击“下载并更新”。旧版若卡在等待游戏退出，请先从旧版托盘彻底退出工具再重新打开；仍无法更新时手动完整解压覆盖，保留 `data`、`backups`。请先退出游戏并等待当前存档操作完成，程序目录需要可写。

v0.1.3 及更早版本需退出工具后手动完整解压覆盖一次，保留 `data`、`backups`。
