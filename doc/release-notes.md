## 0.1.8 更新不再检测运行中的游戏

- 下载完成后直接重启更新，不再检测或等待 Wallpaper Engine 和其他游戏退出。
- 仅等待工具当前的存档操作完成，随后自动继续；保留待上传任务和原同步基准，更新不会替用户关闭游戏。
- 包含 v0.1.7 的云端时间显示、界面闪烁、EXE 图标刷新和移除托盘改动；管理窗口关闭即退出，Steam 启动项负责游戏前后自动同步。

Windows 10/11 x64。旧版可通过“检查更新”升级；如果旧版被运行中的游戏拦住，可先退出工具后完整解压覆盖新包，保留 `data`、`backups`。旧版的检测逻辑需要升级后才能移除。程序未签名。
