## v0.1.1 启动前云同步与游戏分组

- 每游戏新增“开始游戏前自动云同步”，默认关闭，通过本工具“开始游戏”入口先同步再唤起 Steam。
- 比较本地、云端及上次同步内容；两端均有新进度时暂停启动，先手动选择同步方向，不静默覆盖本地存档。
- 云端下载前保留本地备份；未登录、网络或路径错误时暂停启动。
- 隐藏 Proton、GE-Proton、Steam Linux Runtime 等兼容层。
- 游戏列表上方显示不支持 Steam 云存档的游戏，下方显示支持的游戏；缺少本地 Steam 元数据时另列待确认。两组都能使用夸克云同步。

下载 ZIP 后完整解压，运行 UmeYc-SteamBack-Windows.exe。适用于 Windows 10/11 x64，无需 Python，程序未签名。SHA256.txt 为下载校验文件。

启动前同步需先完成手动同步及目录对应。直接从 Steam 客户端或原有桌面快捷方式启动不会经过本工具；请使用工具中的“开始游戏”。Windows CI 验证自动测试、打包和 EXE 启动，真实夸克账号与具体游戏跨设备互通仍需联调。
