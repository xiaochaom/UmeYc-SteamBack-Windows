## 0.1.9 修复启动时误报已有同步会话

- 启动会话绑定入口进程、创建时间和唯一标识，失效会话记录不再阻止正常启动。
- 同一次启动重试复用同步结果；同一启动链重复调用同步入口时只由最外层执行同步和退出上传。
- 迟到的旧会话退出消息不会清掉新的活动会话，独立重复启动仍保留保护。
- 保留 v0.1.8 的直接重启更新：不检测或等待 Wallpaper Engine 与其他游戏退出；配置、登录信息和备份保留。

适用于 Windows 10/11 x64。已配置的 Steam 启动项继续有效，无需重新配置。可通过“检查更新”下载升级，或退出工具后完整解压覆盖，保留 `data`、`backups`。程序未签名。
