# UmeYc-SteamBack-Windows

Windows 游戏存档管理工具，通过夸克网盘与 [UmeYc-SteamBack Steam Deck 插件](https://github.com/xiaochaom/UmeYc-SteamBack)互通。

![云存档](src/umeyc_steamback/assets/cloud-save.svg)

## 功能

- 中文界面，识别 Steam 多个游戏库与账号；可以手动填写 Steam App ID。
- 隐藏 Proton、GE-Proton、Steam Linux Runtime 兼容层，其余游戏统一按名称排列，不区分 Steam 云支持情况。
- 每次程序启动时在独立后台任务中检查 GitHub 正式版本；发现新版显示下载入口，也可手动检查。更新失败不影响存档同步或游戏启动，后台不弹窗。
- 夸克 App 扫码登录，夸克和 Steam 账号栏只显示昵称。Windows 会话使用当前用户 DPAPI 加密。
- 候选路径识别、手动选择存档文件/目录、游戏保存前后的文件变化嗅探；无需游戏支持 Steam 云。
- 手动备份到本地，可重命名、恢复、删除。备份持续保留，没有固定或滚动删除机制。
- 本地上传夸克、夸克同步到本地，展示本地存档时间、云端存档时间及上传时间。
- 每游戏只有一个“自动云同步”开关，默认关闭：开始游戏前同步，退出游戏后上传。
- 配置 Steam 启动项后，从 Steam 或原有 Steam 快捷方式正常启动；同步后台按需唤起，上传完成后自动退出，无需开机自启。
- 云端每个 Steam 账号、每个游戏仅保留最新一份；发布成功后才清理旧版本。
- 下载校验 SHA-256、文件清单、Steam 账号与游戏 ID；覆盖前持久保存本地备份。

## Windows 运行

支持 Windows 10/11 x64。初版尚需真实账号和游戏联调；跨平台游戏本身的存档格式必须兼容。

打开仓库 [Releases](https://github.com/xiaochaom/UmeYc-SteamBack-Windows/releases/latest)，
下载 `UmeYc-SteamBack-Windows.zip`，解压并保持完整目录结构，运行
`UmeYc-SteamBack-Windows.exe`。不需要安装 Python；`SHA256.txt` 可用于校验下载文件。
程序未签名。发现新版后点击“下载新版”打开正式发布页，完整解压新版本；替换程序前请等待同步完成并退出工具。配置、登录信息和备份都放在程序旁的 `data`、`backups` 文件夹，升级时请保留这两个文件夹；移动程序时一起移动。保留原程序路径可继续使用已配置的 Steam 启动项。主分支及功能分支构建同时在 [Actions](https://github.com/xiaochaom/UmeYc-SteamBack-Windows/actions)
提供 30 天有效的调试制品。只有推送版本标签才会在所有 Windows 检查通过后发布 Release。

源码运行（Python 3.11/3.12）：

```powershell
git clone git@github.com:xiaochaom/UmeYc-SteamBack-Windows.git
cd UmeYc-SteamBack-Windows
py -3.12 -m venv .venv
.venv\Scripts\python -m pip install -e ".[dev]"
.venv\Scripts\python -m umeyc_steamback
```

## 第一次与 Deck 互通

1. 在 Deck 上传该游戏存档，Windows 扫码登录同一个夸克账号。
2. 选择同一个 Steam 账号和游戏 App ID。账号栏显示昵称，内部使用 **32 位 Account ID** 隔离存档；“填写账号 ID”也接受 SteamID64 并转换。
3. 选择 Windows 上游戏实际使用的存档文件或文件夹。例如 Deck 的 `proton/drive_c/users/steamuser/AppData/Local/某游戏/Saved` 对应 Windows 的 `%LOCALAPPDATA%\某游戏\Saved`。
4. 点击“云端同步到本地”，程序校验后直接覆盖已配置的实际路径，不再要求逐目录确认。尚未配置路径时先选择一次实际路径；临时解压目录不会成为游戏存档路径。
5. 覆盖前保留本地安全备份。后续 Windows 上传会沿用云端目录标识和相对文件名，Deck 可继续读取。

**优先从已有存档的一端上传，再在另一端建立目录对应。** 如果 Windows 先上传，两端都手动选路径时应选择同一层级、同样的目录顺序，Deck 使用手动路径模式。Windows 对应文件夹可为空，但需先创建并明确选择。选择单个文件时，同一父目录会合并为一个目录槽位。

重新“选择存档路径”会重置为手动路径模式。首次从云端下载会按已选择路径的顺序绑定云端目录标识，并保持所选文件的范围。多个根目录必须一一对应，不能互相包含；数量不符或已有绑定发生变化时会停止覆盖并提示重新选择实际路径。程序不会根据云端绝对路径直接写文件。

## 找不到存档时

“识别候选路径”检查当前游戏的 Steam `userdata/.../remote` 和常见用户目录中与游戏名称/安装目录同名的位置，候选需要人工确认。它不是完整游戏存档数据库，无法保证识别任意游戏。

“开始嗅探”记录用户 Documents、Saved Games、AppData、该游戏安装目录和 Steam 账号目录中的文件状态。随后启动游戏、保存一次进度、退出，再点“完成嗅探”，勾选真实存档。缓存、配置也可能变化，所以嗅探不会自动采用路径或上传。单次扫描最多 10 万文件、20 秒；达到限制会提示，仍可手动选择路径。不会扫描整个磁盘。

## 自动云同步与 Steam 启动项

完成首次手动同步及路径对应后，在游戏页面打开“自动云同步”。一个开关同时控制开始前同步和退出后上传，默认关闭。旧配置只有一个方向开启时会迁移为关闭；原本两个方向都开启时继续开启。

首次开启会显示 Steam 启动项配置：

1. Steam 正在运行时，点击“复制启动项”和“打开游戏属性”，将生成内容粘贴到启动选项；无需重启 Steam。
2. 也可以自己完全退出 Steam，再点击“Steam 已退出，直接写入”。工具会先备份配置，只为该游戏增加同步入口，保留原有参数及 `%command%` 包装命令，不会关闭或重启 Steam。
3. 此后直接在 Steam、Steam 原有桌面快捷方式中启动游戏。Steam 先运行同步入口，同步通过后才运行原游戏命令；退出后后台等待存档写入稳定，再上传。没有开机自启项，也无需更换游戏快捷方式。

关闭“自动云同步”会跳过同步，原有游戏参数仍保留。请保持工具的程序目录可用，移动目录后需要重新配置启动项。此方式适用于 Steam 游戏，不包含其他启动器和非 Steam 快捷游戏。

启动前比较本地、云端与上次同步的内容哈希：一致则直接启动，云端有新进度且本地没有未上传修改时自动下载并备份，只有本地进度变新时保留本地。两端均有新进度或首次同步存在不同内容时暂停启动，先手动选择同步方向。未登录、网络失败、路径错误也暂停启动，避免在游戏运行后覆盖。

检查云端读取小型 JSON 索引，包含内容哈希、存档时间和版本；无需每次下载完整 ZIP。当前本地比较仍需扫描、打包并计算内容哈希。只有需要拉取新进度时才下载存档包，并校验摘要。

包装入口不创建页面；按需后台收起管理窗口并停止页面绘制与刷新，每 5 秒检查已开启的游戏。正常同步不弹窗；失败记录在托盘“查看后台同步记录”，退出上传失败会保存任务并以 60～900 秒间隔重试。每次补传都重新读取云端索引，并与任务创建时的同步基准比较；云端出现不同进度时暂停补传，不自动覆盖。内容已经一致时直接结束任务。手动同步成功或关闭自动同步会清除对应待补传任务。所有游戏结束、上传完成后，按需后台自动退出。主动打开管理窗口后会保留界面，关闭窗口可收起到托盘，托盘可显式退出。退出程序或关机前尚未完成的上传会在下次运行继续尝试。

Windows 的真实 Steam 启动项、反作弊及启动后脱离父进程的第三方启动器仍需设备验证。工具按 Steam 运行标记和游戏目录进程辅助判断退出；不要在上传完成前强制关机。Deck 插件使用 Steam 游戏模式的启动请求，不需要配置 Windows 启动项。

游戏列表不再读取 Steam 云支持元数据或显示支持情况分组。手动添加的游戏与已安装 Steam 游戏统一排列，选择存档路径后可使用夸克同步。

## 备份、恢复与时间

所有工具数据跟随程序所在磁盘，不再默认写入 C 盘用户目录：

- `程序目录\data`：配置、加密登录会话、同步记录、待补传队列、Steam 配置备份及传输临时文件。
- `程序目录\backups\<Steam Account ID>\<App ID>`：本地游戏备份、云端下载记录及覆盖前安全备份。

源码运行时使用仓库根目录下的 `data` 和 `backups`。旧版 `%LOCALAPPDATA%\UmeYc-SteamBack-Windows` 数据在首次启动时迁移；先退出旧版，逐文件复制并校验成功后才删除原文件。同名内容冲突、空间不足或目录不可写时停止迁移，不会覆盖冲突文件或退回 C 盘存储。请将完整程序目录放在可写位置。

卸载游戏不会删除这些备份。清理工具时退出程序后删除整个程序文件夹即可；游戏本身的存档和夸克云端文件保留。使用过自动同步启动项时，请先从 Steam 游戏启动选项中移除本工具增加的入口，保留原游戏参数，避免删除工具后无法启动。不要将 `data`、`backups` 或包含它们的目录选为存档来源。移动到其他 Windows 用户或电脑后，DPAPI 登录会话需要重新扫码。

存档时间取所选文件中**最新的修改时间**；上传时间表示云端发布发生的时间。时间不同不一定表示进度不同，同步冲突还比较内容哈希。云端未知版本需要确认后才能覆盖，上传中发现另一台设备更新则停止发布。夸克没有提供本项目可用的跨设备原子锁，极窄的并发发布窗口仍可能产生多个索引，后续上传会按服务器时间保留最新版本。尽量避免两端同时上传同一个游戏。

从云端下载会保留“云端下载”和“同步前本地备份”；恢复本地记录会保存“恢复前本地备份”。恢复覆盖同名文件，保留额外的本地文件。恢复覆盖前备份可移除那次同步新建的文件。删除记录只删除备份，不删除游戏当前存档。

游戏运行时禁止备份、恢复和同步。检测依据 Steam 的运行状态与游戏安装目录中的进程；特殊启动器可能无法完全识别，请先退出游戏再操作。自动上传在检测到退出后等待一段时间；文件仍在变化时会延后重试并记录原因。后台由游戏启动按需运行，显式退出程序后停止监控；不安装系统服务。

夸克目录沿用 `/UmeYc-SteamBack/<Steam Account ID>/<App ID>/`，使用 Deck `format=1` 清单及归档。清理只涉及该目录中符合插件文件命名规则的旧版本，不清空夸克回收站，也不会删除其他文件。
